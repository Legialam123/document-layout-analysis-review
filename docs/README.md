# Tài liệu / Documents

Lưu **bài báo Springer LNCS và poster khoa học A0 do tác giả repository biên soạn** vào đây nếu muốn công bố. Có thể tạo các thư mục `paper/`, `poster/` khi tải file từ Overleaf.

Không tải bản PDF DocLayNet gốc hay hình ảnh có bản quyền của bên thứ ba nếu chưa có quyền phân phối lại. Luôn giữ tên tác giả và trích dẫn đầy đủ trong tài liệu.
